# Task Manager

## Beschrijving

Een Task Manager API gemaakt met Python en FastAPI. Gebruikers kunnen taken toevoegen, bekijken, aanpassen en verwijderen.

## Technologieën

* Python
* FastAPI
* SQLite / SQL
* Pytest
* Git & GitHub
